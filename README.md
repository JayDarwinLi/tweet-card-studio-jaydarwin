# Tweet Card Studio · JayDarwin Edition

一个用于把推文、长文观点和个人内容快速制作成社交媒体图片卡片的本地工具。

它适合将 X / Twitter 内容重新整理为抖音、小红书、视频号、公众号等平台可直接发布的竖版图片，也可以作为个人内容素材库使用：搜索历史内容、按主题筛选、选择背景、调整卡片样式，然后导出 PNG 或动态 Live 图素材。

## 主要用途

- **内容二次分发**：把推文和长文观点转换成适合中文社交平台的图片卡片。
- **个人内容管理**：集中保存历史推文，支持关键词、主题、时间和热度筛选。
- **个人品牌统一**：固定头像、名称、用户名、主题色和卡片视觉风格。
- **批量背景管理**：一次选择整个图片文件夹，建立自己的背景图库。
- **快速批量出图**：通过带参数的链接或 Agent 指令复用同一套样式。
- **本地隐私处理**：文字、头像、背景和导出过程主要在浏览器本地完成。

## 二开升级功能

- 内置整理后的推文素材库和主题分类。
- 支持自定义文案和导入自己的推文 JSON。
- 支持 3:4 竖图、9:16 竖图和透明背景纯卡片。
- 支持自动字号、卡片大小、透明度、背景压暗和安全区参考线。
- 支持导出 PNG 和 3 秒动态 MP4 素材。
- 支持单张背景、图片 URL和文件夹批量背景导入。
- 批量导入的背景保存在浏览器 IndexedDB，刷新页面后仍可继续使用。
- 提供 Windows 便携启动器，不要求安装 Python、Node.js 或其他开发工具。

## Windows 便携版使用

### 第一次使用

1. 下载仓库 ZIP，或者复制完整的 `Tweet-Card-Studio-Portable` 文件夹。
2. 解压后保留完整目录结构，不要只复制启动文件。
3. 双击 **`双击启动推文卡片生成器.cmd`**。
4. 程序会调用 Windows 自带的 PowerShell，在本机启动服务并自动打开：

   ```text
   http://127.0.0.1:8798/
   ```

不要直接双击 `index.html`。浏览器需要通过本地 HTTP 服务读取推文库和背景资源。

### 换电脑迁移

复制整个文件夹到另一台 Windows 10/11 电脑即可继续使用。便携包已经包含：

- 网页程序与导出组件
- `posts.json` 推文素材库
- `profile.json` 默认账号资料
- `backgrounds` 内置背景图库
- 不依赖 Python 的 PowerShell 本地服务器

通过页面“选择图片文件夹”导入的背景属于旧电脑浏览器数据，不会自动写入仓库。迁移时请同时复制原背景图片文件夹，到新电脑后重新选择一次。

## 基本操作

1. 在“历史推文”中搜索或选择内容，也可以切换到“自定义文案”。
2. 在“样式”中选择画布比例、卡片主题、字号和透明度。
3. 在“背景”中选择内置图片、上传单张图片，或者批量选择图片文件夹。
4. 拖动卡片调整位置，使用安全区参考线检查平台遮挡区域。
5. 点击“下载 PNG”或“导出 Live 图”。

## 导入自己的推文

页面支持导入 JSON 数组，每条内容仅 `text` 必填：

```json
[
  {
    "date": "2026-01-01",
    "text": "这里是推文正文，支持换行。",
    "topic": "AI与科技",
    "tags": ["长推", "金句"],
    "sourceUrl": "https://x.com/example/status/123",
    "metrics": {
      "likes": 0,
      "replies": 0,
      "reposts": 0,
      "bookmarks": 0,
      "views": 0
    }
  }
]
```

也可以直接替换项目根目录的 `posts.json`，刷新页面后加载。

## 项目结构

```text
Tweet-Card-Studio-Portable/
├─ index.html                         页面结构
├─ styles.css                        UI 与卡片样式
├─ app.js                            素材库、背景、导出等功能
├─ posts.json                        默认推文素材库
├─ profile.json                      默认账号信息
├─ backgrounds/                      内置背景与清单
├─ vendor/                           本地导出依赖
├─ 双击启动推文卡片生成器.cmd          Windows 一键入口
├─ launch-portable.ps1               启动与状态检查
└─ portable-tcp-server.ps1           无外部依赖的本地服务器
```

## 开发方式

这是一个纯静态 HTML/CSS/JavaScript 项目，不需要构建步骤。修改 `index.html`、`styles.css` 或 `app.js` 后刷新浏览器即可查看效果。

如果电脑已经安装 Python，也可以在项目目录运行：

```bash
python -m http.server 8798 --bind 127.0.0.1
```

## 隐私说明

账号设置、手动导入的推文和文件夹背景默认保存在当前浏览器。导出图片在本机生成。只有主动使用“X API 同步”或粘贴网络图片 URL 时，应用才会访问相应网络服务。
