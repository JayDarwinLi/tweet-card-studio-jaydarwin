Tweet Card Studio 便携版
========================

使用方法：
1. 把整个 Tweet-Card-Studio-Portable 文件夹复制到新电脑，或解压 ZIP。
2. 不要单独复制启动文件，也不要直接双击 index.html。
3. 双击文件夹里的“双击启动推文卡片生成器.cmd”。
4. 程序会使用 Windows 自带的 PowerShell 启动本地服务器并打开浏览器。

系统要求：Windows 10 或 Windows 11。
默认地址：http://127.0.0.1:8798/
不要求安装 Python、Node.js 或其他开发工具。

已经随文件夹迁移的数据：
- 当前 posts.json 推文库
- profile.json 默认账号信息
- 内置 backgrounds 背景图库
- 页面代码、导出组件和全部本地资源

需要单独迁移的数据：
- 通过网页“选择图片文件夹”导入的背景存放在旧电脑浏览器中。
- 请同时复制原背景图片文件夹，到新电脑后重新选择一次。
- 在页面内临时修改、仅保存在浏览器 localStorage 的设置也需要重新设置。

隐私：网页和图片处理均在本地完成。只有使用“X API 同步”时才会访问相关网络接口。
